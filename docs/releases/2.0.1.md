# DataM8 Desktop 2.0.1

This patch bundles Generator 2.0.1 to preserve umlauts and other Unicode characters
in model JSON and generated output, including on Windows.

## Fixes

- Use UTF-8 consistently when saving models, importing or refreshing source
  metadata, and generating output.
- Open legacy Windows-1252 solutions by converting affected JSON files to UTF-8
  before loading, without retaining backup files. Existing UTF-8 and ASCII files
  remain unchanged.

## Compatibility

The DataM8 schema version remains **2.0.0**. Automatic conversion covers the
solution file and its Base/Model JSON, including folder metadata. Plugins,
templates, transformation Python files and existing output are outside this
conversion. Generate again to replace existing output with UTF-8. Text already
corrupted inside valid UTF-8 is not automatically repaired.

See the [canonical backend contract](../../submodules/datam8-generator/docs/backend-contract.md)
for conversion behavior and [release verification](../release.md) for the native
build and signing process. Exact backend/schema commits and verification
provenance are recorded in the published build manifest.
