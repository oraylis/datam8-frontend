# DataM8 Desktop 2.1.0

This release bundles DataM8 CLI 2.1.0, improves solution switching and reload, and
updates the Windows application icon while reducing the bundled Python runtime.

## Improvements

- Switch between local solutions using a reusable backend process, with workspace
  checks that reject stale writes and preserve the previous workspace when opening
  another solution fails.
- Reload the current solution from disk and release editor interaction after a
  failed workspace open. Detect malformed solution files more reliably.
- Keep newly created Base items in the selected collection file.
- Activate dialog primary actions with Enter while preserving editor keyboard
  behavior.
- Use a rounded Windows taskbar icon with a larger original infinity symbol and
  the existing blue-to-red gradient.
- Reduce bundled Python runtime contents while retaining connector dependencies,
  and verify installed distributions on all four supported platform targets.
- Keep the development update simulation usable after version upgrades by offering
  a newer demo version relative to the running app.

## Bundled CLI and compatibility

The embedded CLI is pinned to the exact commit of
[DataM8 CLI v2.1.0](https://github.com/oraylis/datam8-cli/releases/tag/v2.1.0).
It adds local model maintenance, nested edits, source and function operations,
schema discovery, compact JSON responses and ordered batches. It also fixes
generation receipts for external output paths and structured generation failures.

CLI JSON output now uses normalized success/error envelopes and compact summaries;
existing scripts consuming older output must adapt. The `secrets show` command is
removed. Use `secrets check` or `sources test-connection` instead. Each completed
batch operation is saved; failed batches do not roll back earlier changes.

The DataM8 schema version remains **2.0.0**. See the bundled
[CLI contract](https://github.com/oraylis/datam8-cli/blob/v2.1.0/docs/cli-agent-contract.md) and
[backend contract](https://github.com/oraylis/datam8-cli/blob/v2.1.0/docs/backend-contract.md).

## Installation and verification

The release provides Windows x64, macOS Intel, macOS ARM64 and Linux x64 packages.
Windows installers use Authenticode signing; macOS and Linux packages include
detached GPG signatures. Windows updates retain publisher-signature verification;
macOS and Linux updates remain manual.

See [installation and verification](https://github.com/oraylis/datam8-frontend/blob/v2.1.0/docs/desktop-installation.md). The published
build manifest records the exact frontend, CLI and schema commits and links the
four-platform verification run.
